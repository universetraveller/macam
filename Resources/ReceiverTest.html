Instructions and privacy
  1. Start Macam from its menu-bar icon. Leave Playback exclusion Off. Select Whole system or the source browser.
  2. Play audio in Chrome or Safari, in a separate source tab. Source and receiver may use the same browser. Keep receiver input monitoring off.
  3. Click Grant audio-input access, allow permission, select Macam Audio, and Connect.

This offline file sends no data and never plays captured audio. The permission button opens the browser’s current input without recording or monitoring it while you choose Macam Audio (at most 30 seconds). That track closes on Connect or Stop. It does not change the macOS default input. Actual test capture requires the specifically named Macam Audio device.

Stopping Macam removes its device and ends the browser stream. This page tries reconnecting only to the same virtual input. Other websites may require reselecting the input or reloading.
