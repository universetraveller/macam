# Security reports

Report potential security vulnerabilities using the repository's private
vulnerability-reporting feature when it is enabled. If no private reporting
channel is available, open an issue requesting a private maintainer contact
without including exploit details, credentials, private audio, or personal data.
No dedicated security email or response-time commitment is currently published.

The latest development version is maintained on a best-effort basis; no long-term
support release is designated. Local packages are ad-hoc signed and not notarized.

Macam intentionally publishes an input while capture is active. Other local audio
clients may enumerate it subject to macOS permissions. Source selection and optional
playback exclusion are audio-routing controls, not security isolation boundaries.
The app has no network client, account, telemetry, or update service.
